          How verification works

          1. Define requirements. Each becomes a structured rule with an explicit threshold and absence policy.
          2. Confirm the rule set. Rules are immutable once confirmed, and every result cites the version used.
          3. Submit a video. AdProof ingests it, builds a spoken index and one focused visual index per visual rule.
          4. Retrieve evidence. Each rule runs versioned searches for supporting and conflicting moments.
          5. Measure deterministically. Durations, counts, and thresholds are computed in code — never by a language model.
          6. Review. Open any finding at its exact timestamp, with full provenance.

          Only two rule types are implemented: required spoken phrase, and minimum visual duration. Subjective requirements are routed to human review and are never machine-scored.
