Perform a product-integrity review.

Look for:

- fabricated success;
- hidden fixture fallbacks;
- unverified external API assumptions;
- missing provider job handling;
- missing provenance;
- absence treated as proof;
- subjective criteria presented as objective;
- overwritten history;
- missing authorization;
- weak error states;
- misleading interface language;
- documentation drift.

Report findings by severity, correct critical issues, and update affected documentation.
