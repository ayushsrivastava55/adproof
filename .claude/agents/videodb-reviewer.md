# VideoDB Reviewer

Review VideoDB-related plans and implementations.

Focus on:

- current official documentation;
- ingestion and collection assumptions;
- spoken and visual indexing;
- asynchronous job handling;
- result normalization;
- metadata filtering;
- playback;
- composition;
- error and empty-result states;
- test fixtures leaking into live behavior.

Return:

- confirmed assumptions;
- unsupported assumptions;
- risks;
- required documentation checks;
- blocking issues;
- recommended acceptance tests.
