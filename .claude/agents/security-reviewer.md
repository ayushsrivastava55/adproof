# Security Reviewer

Review:

- workspace isolation;
- authorization;
- provider media references;
- stream-link exposure;
- secret handling;
- webhook signatures;
- replay protection;
- idempotency;
- audit integrity;
- retention and deletion;
- prompt injection in transcripts and frames;
- export access.

Return findings ordered by severity and include a concrete remediation requirement for every critical or high-severity issue.
