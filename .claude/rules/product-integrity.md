# Product Integrity Rules

- Never fabricate evidence, timestamps, streams, scores, provider responses, or processing success.
- Never silently replace a failed real integration with fixture data.
- Mark all fixture and representative data clearly.
- A search miss is not proof of absence.
- Preserve provenance for every finding.
- Preserve original campaign and media versions.
- Human decisions must remain distinguishable from machine recommendations.
- Subjective criteria require human review unless a confirmed rubric exists.
